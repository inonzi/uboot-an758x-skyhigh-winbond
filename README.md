# U-Boot for AN758x (Skyhigh/Winbond 8-bit ECC Fix)

## 修改说明
本分支在原版（仅支持 Winbond W29N02KVSIAF）的基础上，增加了对 **烽火 HG5585F / HG5382A (天海/Skyhigh S34ML02G300TFI00 和 S34ML02H200TFI000 颗粒)** 的 8-bit ECC 临时迁移支持。

- **核心改动**：在 `airoha_en7581_nand.c` 和 TF-A 表中加入了天海的 5 字节 ID 匹配，触发 8-bit ECC。
- **网页提示**：更新了 Web 恢复界面的中英文提示文案。

## ⚠️ 刷机指南（极其重要，请勿跳过！）
这是一个“8-bit 读 / 4-bit 写”的临时迁移固件，用于拯救因原厂 8-bit 布局导致变砖的机器。

1. **第一次刷机必须重建 UBI**：进入 U-Boot 网页后，点「重建 UBI」，这会清空整个 UBI 分区（包括 fip 卷）。
2. **按顺序重刷**：重建之后，必须重新刷入：① 官方 preloader → ② 官方 bl31-u-boot.fip → ③ 板级数据/系统镜像，然后才能重启！
3. **救命后门**：如果开机卡住，接上 TTL 串口线，在终端里敲 `nandecc 4`，它就能瞬间切回 4-bit，让你重新救砖。
